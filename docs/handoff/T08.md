## Change
1. **F12, one freshness component** (e.g. `DataAgeBadge`) used everywhere data has an age: METAR, TAF, PIREPs, winds aloft
   (for-use window), TFR and AIRMET/SIGMET layer data, NOTAMs, chart cycle.
   - Neutral when fresh; amber "OLD"/"EXPIRED" when past the product's useful life.
   - Red only when using the data would be unsafe. Document the thresholds per product in docs/DESIGN.md.
   - Replace WeatherBadge, the winds "Current/Not current" pill, and the ad-hoc layer "Data age" rows.
2. **F9, recording control** (beads efb-77r.12).
   - Neutral idle style, not warning red.
   - A clear recording state: "REC 00:12:34" pill with elapsed time, and the audio level if available.
   - A permission-denied state that says how to fix it (Settings).
   - Verify end to end in the simulator that tapping record actually starts and stops a recording, and fix it if not. Note
     that the simulator needs microphone/speech permissions granted via `xcrun simctl privacy`.
3. **State maps** for every async surface: loading / empty / error (with retry) / stale. Covers the airport sheet sections,
   nearest list, search results, layer data loads, chart PDF and offline downloads.
4. **Haptics.** Light impact on toggles; success/warning notification for alerts (TFR/proximity, recording start/stop). Never
   repeat continuously.
5. **Animation.** Pressed states for all custom buttons. No decorative animation on the map in flight.

Record the inventory in docs/DESIGN.md `## Microinteraction Inventory` (interaction | trigger/rules/feedback/loops | fix |
status) and mark F9 and F12 fixed.
