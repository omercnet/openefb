## Change
1. **F1 (sev 4), landable nearest.**
   - Exclude heliports and seaplane bases. Require at least one runway with a hard or turf surface and length ≥ the active aircraft profile's minimum runway (add a field only if one exists; otherwise default 1,500 ft and make it a constant).
   - Show the longest runway length and surface on each row and in the HUD. Flag private-use fields.
   - Check the bundled DB columns (`airports.type`, `ownership`, `runways`).
2. **F2 (sev 4), NRST button.**
   - Replace the 11pt capsule with a fixed, prominent NRST control ≥60pt tall, labelled "NRST". Showing the nearest landable ident, distance, bearing and runway is fine.
   - One tap opens the list. Each row has a large "Direct" action that starts Direct-To (existing direct-to logic).
   - Place it where a pilot finds it under stress and keep it consistent; avoid the top-left record and search area.
3. **F3, follow ownship.** Follow mode on by default. A user pan suspends it and shows a large "Recenter" button (≥60pt); tapping recentres and re-engages. Keep the current zoom on recentre.
4. **F4, track-up.** Rotate the camera to the GPS track yourself and keep our chevron. NEVER use MapLibre `userTrackingMode` or `showsUserLocation` (they draw the system blue puck). Show a north indicator when rotated.
5. **F7, mode toggle.** A text toggle showing the current mode ("N↑" / "TRK↑"), separate from Recenter.
6. **F5, GPS status.**
   - A status chip: OK / Degraded (no altitude, or horizontal accuracy > 50 m) / Lost (with seconds since last fix).
   - When the last fix is > 5 s old, grey out the ownship chevron and the instrument values.
   - Fix "No GPS" overlapping the TRK label.
7. **F8, airport query radius.** Size the airport/navaid query from the visible map bounds, not from 200/2^(z-5). Cap the result count sensibly so low zoom stays fast.
8. **F18, instrument strip.** Values ≥ 28pt monospaced, labels ≥ 13pt, readable over the sectional.
