## Change
1. **Vertical speed.** TrackRecorder must compute vertical speed in feet/minute from successive fixes.
   - Use `location.timestamp`, not `Date()`, with altitude in feet.
   - Smooth lightly (EMA over ~5 s). Ignore fixes with negative verticalAccuracy.
   - Feed the real value into FlightPhaseDetector and TrackPointRecord. Today it is hardcoded 0, so the phase never leaves taxi.
2. **Live phase and audio level.**
   - Something must call `RecordingCoordinator.syncPhaseAndLevel()` periodically while recording, e.g. a 1 Hz task owned by the coordinator, cancelled on stop.
   - Wire `TranscriptionService.setCurrentPhaseProvider` so transcript segments carry the real phase.
   - Remove the hardcoded "cruise" in the SFSpeech path.
3. **SpeechAnalyzer path.** Carry real confidence where the API provides it; otherwise mark it unknown (don't fake 0.9). Set audioStartTime and audioEndTime relative to recording start so replay highlighting works.
4. **AudioRecorder.** Don't swallow `file.write` errors. Log them and stop the recording with EFBError.recordingFailed through the existing error path, so a full disk doesn't silently lose audio.
5. **Cleanup.** Remove the dead `RecordingCoordinator.makeDefault()`, and the placeholder default arguments if nothing needs them. Fix Swift 6 isolation warnings in files you own only when trivial; a later ticket does the rest.

## Acceptance
- New tests:

  - The phase detector reaches takeoff/climb on a realistic synthetic track (taxi, then accelerate to 60 kt, then climb at 600 fpm).
  - syncPhaseAndLevel updates state.
  - The phase provider tags segments.
- Full unit suite green. Report counts.
