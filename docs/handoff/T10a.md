# T10 phase A: night mode + in-flight controls + map VoiceOver (dashboard ticket T10; beads efb-77r.3)

The full brief is docs/handoff/T10.md. To run in parallel with T07 (visual hierarchy), this phase is limited to the map and the
night-mode mechanism. T07 owns, and is editing right now: AirportInfoSheet + section views, LayerControlsView,
Views/Components/*, Core/DesignTokens.swift (new), and the airport/ownship symbol paint in MapService. Don't edit those
files in this phase. If you need a toggle in the layer panel, put the night-mode toggle on the map controls instead.

## Scope (you own)
- A night-mode mechanism: a `DisplayMode` (day / night / auto) in AppState or UserDefaults.
  - Auto follows the system appearance, or sunrise/sunset at the current position if that is simple and offline-safe.
  - Apply it app-wide with `.preferredColorScheme` and a cockpit night palette: dark backgrounds, low-luminance text, no bright whites.
- Map dimming at night: MapService raster/vector paint for the base and sectional layers (brightness-max / saturation, or a dark overlay) and dark map chrome.
  - Coordinate with T07's symbol-paint edits by re-reading MapService right before editing, and touch only base-layer paint.
- Map controls (MapControlsView, NRST button, Recenter, record button, search button) ≥ 60pt in flight.
- A quick night toggle (moon icon) on the map controls.
- VoiceOver labels and values for every map overlay control and the instrument strip (group cells; never color alone).
