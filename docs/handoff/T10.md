## Change
1. **Night mode (F16).** A cockpit night palette (dark backgrounds, low-luminance text, no bright whites, red/amber kept
   meaningful) that dims the map too: a raster brightness/saturation reduction on the base and sectional layers, plus darker
   UI chrome.
   - Modes: Day / Night / Auto (follows system dark mode, or sunset/sunrise at the current position if simple).
   - Add a quick toggle on the map. Show screenshots of both palettes.
2. **Touch targets (F15).** In-flight map controls ≥ 60pt. Everything else ≥ 44pt.
3. **Dynamic Type.** Semantic text styles everywhere, and no hardcoded font sizes except the instrument readouts (use
   @ScaledMetric there). Map overlays may cap the size with `.dynamicTypeSize(...xxxLarge)` so they don't cover the map; sheets
   and lists must scale to accessibility sizes without truncating critical data.
4. **VoiceOver.** Every control and readout has a label/value. Group instrument cells. Never convey meaning by color alone
   (category dots also get text).
5. **Contrast.** ≥ 4.5:1 in both palettes. Check with Increase Contrast.
6. Fill in the HIG score (the skill's scoring) before and after in docs/DESIGN.md.
