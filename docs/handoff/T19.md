issues. Read each one with `bd show <id>`.

1. **efb-u74 (most important): proximity alerts ignore altitude.**

   - When altitude is unknown (GPS Degraded), say "near", never "inside".
   - Tests with stacked SFO Class B shelves: below a shelf, inside a shelf, above the ceiling.
2. **efb-lmv: show military fields as MIL** in the Nearest list and on the NRST button, like PVT. Keep them listed for emergency use.

   debounce scheduler so the tests are deterministic. Run the suite 3 times in a row to show it's stable.
