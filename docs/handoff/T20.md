# T20: Recorded flights never appear (beads efb-3ci, P1; dashboard ticket T20)

`bd show efb-3ci`. After a recording stops, nothing inserts a `SchemaV1.FlightRecord`, and no logbook entry is created.
Flights > History stays empty, so Replay and the AI Debrief (the PRD's differentiating features) can't be reached.

## Change
1. When a recording stops, create the `FlightRecord` (SwiftData) from the RecordingCoordinator's summary, linking to the
   recording-database flight ID (track, audio, transcript). Also create the draft logbook entry the existing
   `LogbookViewModel.createFromRecording` path expects. Find the right owner (RecordingViewModel or coordinator stop
   handler) and keep a single code path.
   - Handle a short or aborted recording: discard with no track points, or keep with a clear "no data" state. Pick one and
     document it.
2. End-to-end verification in the simulator, using `tools/fly.sh` and a SIM_TAG simulator claimed via tools/sim-test.sh.
   Record a ~2-minute flight from KPAO, stop it, then check:
   - the flight appears in Flights > History;
   - Flight Detail opens;
   - Replay plays the track;
   - Debrief shows its availability state (Apple Intelligence is likely unavailable in the simulator; the unavailable state
     must be clear);
   - the logbook has a draft entry with the departure airport.
   Screenshot each step into docs/design/screenshots/T20/.
3. Tests: stopping a recording creates exactly one FlightRecord and one draft logbook entry with the right
   date/departure/duration; a recording with no track points behaves as decided in (1).
4. While there, do efb-zfm.9: set the UI-test target to Swift 6 (no throwaway UI tests remain once you delete yours) and fix
   any warnings.

The release-prep agent couldn't capture the store screenshot of flight replay/debrief because of this bug. After the fix,
add `dist-prep/screenshots/09-replay.png` (iPad 13", 2064×2752) from the flight you recorded.

Follow docs/handoff/COMMON.md: claim a simulator with `export SIM_TAG=$(tools/sim-test.sh claim T20)` and release it when done.
