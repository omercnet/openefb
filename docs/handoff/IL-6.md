# IL-6: Israel NOTAM and route-closure service (beads efb-aac.7; dashboard ticket T07)

Owner decision (Q3 = A): a small server scrapes the IAA NOTAM page once and serves JSON. The app never hits the IAA site
directly. Background: docs/research/israel-cvfr.md §6, with samples `iaa-notam.txt` and `iaa-notam-detail.txt` in
docs/research/israel-cvfr-samples/.

## Part A: Service in `services/il-notam/` (TypeScript, deployable to Vercel like ~/dev/pilot-interviews)
- **Scraper:** fetch the IAA NOTAM list (`https://brin.iaa.gov.il/aeroinfo/AeroInfo.aspx?msgType=Notam`, ASP.NET
  WebForms), then the detail page per NOTAM id (see the research for the mobile detail endpoint).
  - Be polite: one run every 15 minutes at most, a detail cache by NOTAM id plus its "Created" stamp, sequential
    requests with a delay, and an honest User-Agent naming OpenEFB with a contact URL.
- **Parser:** ICAO NOTAM fields: number, NOTAMR/NOTAMC, Q-line (FIR, code, traffic, purpose, scope, lower and upper
  limits, centre and radius), A/B/C/D/E/F/G.
  - Coordinates in E) (e.g. `N323122E0345511`) become polygons; circles come from the Q-line radius.
  - **CVFR closures:** "CVFR RTE CLSD A-B-C" → ordered chains of 5-letter point codes, including several chains per
    NOTAM and the variants in the samples.
  - Keep the raw text with each item. Never drop a NOTAM because it doesn't parse; mark it `parsed: false`.
- **Output:** `notams.json`: `generatedAt`, `source`, `items[]`, with `closures[]` as code chains and their validity.
  - Store it in Vercel Blob or a static path, generated by a cron route and served with cache headers.
  - Add a `/health` that reports the age of the last successful scrape.
- **Tests:** Vitest on the saved samples (list parse, detail parse, Q-line, coordinates, closure chains, NOTAMC
  cancellation). Fetch fresh samples while building, and save them.
- **Deployment:**
  - You can't deploy: there's no Vercel login on this machine. Run it locally (`vercel dev`, or a plain node script
    that writes `notams.json`) and prove a real scrape works from this Mac.
  - Write a README covering the deploy steps the owner runs (`vercel login`, `link`, blob store, `CRON_SECRET`).
  - **Risk to test:** IAA may geo-block or WAF-block non-Israeli cloud IPs. Note it in the README and add a fallback
    mode the owner can run on any always-on Israeli or home machine (the same script plus a static upload). Don't build
    the fallback unless it's trivial.

## Note (WEB-1, 2026-11-01): the service moved
`services/il-notam/` no longer exists. It is now `web/notam-relay/`, a Cloudflare Worker (Vercel Hobby can't run a
15-minute cron). Parser, `build.ts` and the Vitest suites moved unchanged apart from: web-standard `TextDecoder` instead
of iconv-lite, Workers KV instead of Vercel Blob, a per-run cap of 40 detail requests (Workers free plan: 50
subrequests), and cached items reused as stored (re-parsed only when `PARSER_VERSION` changes). The feed shape
(`notams.json`) is unchanged; its URL is now `https://<worker>.workers.dev/notams.json`, and `/health` replaces
`/api/health`. Deploy steps: `web/README.md` and `web/notam-relay/README.md`. The text above is kept as history.
