# T11: Georeferenced FAA airport diagrams on the map (dashboard ticket T11; beads efb-22s)

Run `bd show efb-22s` and read tools/apd-georef/README.md + tools/apd-georef/prototype.swift (the prototype, ~70% success).

## Goal
When the pilot zooms close (≥ ~14) near an airport, draw that airport's FAA airport diagram on the map, anchored at its real
position and aligned to true north, rotating with the map, under ownship. A wrong overlay is worse than none, so only show
diagrams whose georeference passed validation.

## Design (follow unless you find a better approach; record decisions with `bd update efb-22s --notes`)
1. **Shared core.** Put the georeferencing core in ONE Swift file that compiles both in the app and in a macOS command-line tool:
   efb-212/Services/AirportDiagramGeoreferencer.swift. Use PDFKit, CoreGraphics and Vision only; no AppKit/UIKit. Input: PDF data,
   the airport reference point, and runway thresholds from the bundled DB. Output: a page→geo transform plus diagnostics, or a
   rejection reason. Mark it `nonisolated`.
2. **Grid method (from the prototype).**
   - Lat/lon grid labels come from the PDF text layer, with Vision OCR as a fallback (some labels are vector outlines).
   - Snap each label to the vector line/tick ending at it.
   - Least-squares fit with outlier rejection.
   - Conformal gate: N-S vs E-W scale within 3%.
3. **Runway method.**
   - Extract the runway rectangles: long, thick, filled quads in the vector stream.
   - Match them to the DB runway thresholds (`runways` table: base/reciprocal end lat/lon; ~1/3 of runways have coordinates). Solve a similarity transform.
   - Use it both as a fallback when the grid fails and as a cross-check: accept a grid fit only if the predicted thresholds land within ~50 ft (or the runway method agrees within that) whenever thresholds exist.
   - Diagrams are north-up or rotated by 90/180/270; handle rotated pages.
4. **Insets.** "SEE INSET" magnified circles use a different scale. Mask them out of the rendered image so they aren't drawn misplaced on the map.
5. **Batch tool.**
   - tools/apd-georef/ becomes a small SwiftPM or swiftc command-line tool that compiles the shared core.
   - It downloads the current cycle's APDs (the metafile is at https://aeronav.faa.gov/d-tpp/{cycle}/xml_data/d-tpp_Metafile.xml; PDFs at https://aeronav.faa.gov/d-tpp/{cycle}/{pdf_name}), runs all ~925, and writes a report: pass rate, failure reasons, and an accuracy histogram vs runway thresholds.
   - Iterate on the algorithm until ≥ 90% of APDs georeference with no per-airport hand work, or document precisely why that isn't reachable and what the ceiling is.
   - Cache downloads in /tmp/apd-cache (don't commit PDFs).
   - Put the report in docs/design/apd-georef-report.md and add it as a dashboard deliverable.
6. **App integration.**
   - Reuse TerminalProcedureService (charts(for:), pdfURL(for:)) to get the APD PDF.
   - Georeference on device with the shared core and cache the result per cycle (Application Support/efb-212/dtpp/{cycle}/georef/).
   - Render the page to a transparent PNG (white → clear; masks applied).
   - Add an MLNImageSource with an MLNCoordinateQuad and a raster layer BELOW the airport/ownship layers, shown at zoom ≥ 14 for airports in view.
   - Add a layer toggle "Airport diagrams" (default on) with a one-line caveat: "Advisory, verify against the charted diagram".
   - Put all map code in a new file (e.g. efb-212/Services/AirportDiagramOverlay.swift).
   - Make only a minimal hook in MapService.onStyleLoaded and one toggle row in LayerControlsView. Other agents are editing MapService (camera/ownship/airport query) and LayerControlsView right now, so re-read those files immediately before your small edits, and do those hook edits LAST.

## Acceptance
- ≥ 90% automated pass rate on the current cycle (or a documented ceiling), with zero accepted fits that fail the runway cross-check where thresholds exist.
- Unit tests with real PDF fixtures for KPAO (09216AD) and one rotated or OCR-label diagram (e.g. BOS 00058AD): transform within tolerance of DB thresholds; the conformal gate rejects a corrupted fit.
- Visual proof: throwaway XCUITest screenshots at KPAO and KSQL at zoom ~15, north-up and track-up, in docs/design/screenshots/T11/. Add them as deliverables.
- Full unit suite green.
