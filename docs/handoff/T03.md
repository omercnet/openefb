# T03: Database robustness (beads efb-zfm.3, dashboard ticket T03)

## Target (files you own)
- efb-212/Data/* (AviationDatabase, DatabaseManager, RecordingDatabase)
- efb-212/Core/AppState.swift (only the database-service and recording-database members)
- efb-212/Views/Map/CurrencyWarningBanner.swift

  RecordingCoordinator block of the same file.
- The matching tests.

## Change
1. **Fail loudly.**
   - Replace `try? DatabaseManager()` falling back to `PlaceholderDatabaseService` (MapContainerView, FlightPlanView).
   - Create the DatabaseManager ONCE (AppState owns it) and share it.
   - On failure, set an EFBError on AppState and show a clear, non-dismissable banner: "Airport database unavailable — reinstall the app". Never pretend there are no airports.
2. **Bundled DB refresh.**
   - Today aviation.sqlite is copied to Application Support only if missing, so app updates never refresh it.
   - Add a data version (a constant in code and/or a checksum or size of the bundled file) and recopy when the bundled version differs.
   - If the app writes to this DB (e.g. a weather cache), keep the writes but handle the -wal/-shm files on recopy.
3. **Nearest airports.**
   - `nearestAirports(to:count:)` expands a square box, so a corner airport can beat a closer one, and the emergency HUD depends on this.
   - Query a box that covers the circle, compute true great-circle distance, sort, and accept only results within the circle radius searched. Expand the radius until `count` are found within the circle.
4. **Search.** FTS5 MATCH receives raw user text and throws on `"`, `-` or `KPAO-1`. Tokenize and quote safely: split on non-alphanumerics, wrap each token in double quotes, then append `*`. Empty input returns empty results.
5. **One RecordingDatabase.** It is built in 3 places (AppState.getOrCreateRecordingDatabase, MapContainerView, RecordingCoordinator.makeDefault — another agent removes makeDefault). Make AppState the single owner; MapContainerView uses it.
6. **CurrencyWarningBanner.** A failed fetch must not report `.current`, which is an unsafe default. Show "Currency unknown" instead.
7. **DebriefView.** The empty catch around FlightSummaryBuilder.buildPrompt must show an error state.

## Acceptance
- Tests against a temp GRDB database:
  - nearest-ordering with a corner case (an airport at the box corner vs a closer one just outside the first box);
  - FTS with quotes, dashes and empty input;
  - recopy on a version change;
  - DatabaseManager failure surfaces an error.
- Visual check of the DB-failure banner. Simulate the failure with a test-only launch argument (e.g. `-simulateDatabaseFailure YES`) in a throwaway UI test. Put the screenshot in docs/design/screenshots/.
- Full unit suite green. Report counts.
