# L2 port notes (route)

- Port-map L2 is one source file, Core/ActiveRoute.swift (125 lines). The "87 cases" in the L2 row belong to test files that mostly exercise other types (IsraelRouteFollowing = L3, IsraelAlertEvaluator, AppState.updateActiveRouteProgress, NearestAirportViewModel, FlightPlanViewModel/SwiftData). Those cases port with their own tickets, using `domain/route` from main. No Swift test targets ActiveRoute alone, so `activeRoute.test.ts` is new characterisation of its methods (8 cases).
- `ActiveRoute` is an immutable value: `advance`/`goBack` return the next state (same object when it cannot move). Properties become functions (`currentLeg(r)`, `isLastLeg(r)`, ...). Dates are epoch ms.
- `DEFAULT_OFF_ROUTE_THRESHOLD_NM = 1.0` is duplicated from `IsraelRouteFollowing.defaultOffRouteThresholdNM` (L3) to avoid a forward dependency; L3 should re-export or reuse it.
- `legPublishedAltitudesFeet` matches ASCII digit runs; Swift's `isNumber` also accepts non-ASCII digits and fractions. Irrelevant for CAAI data.
